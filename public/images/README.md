# Original editorial illustrations

culture.svg, lifestyle.svg, entertainment.svg and technology.svg were created as original repository-native vector artwork for this project. They illustrate general themes and do not portray actual photographed places or events. No third-party stock photography or invented image licences are used. The site owner should confirm rights and approval for these assets before publication. Uploaded images require the owner's documented licence or permission.

## Generated editorial scenes

The seven WebP assets added in the revised edition were created with the built-in image_gen tool for this project, then resized and compressed with Sharp. They are AI-generated imagined scenes, not real venue documentation. No people or nudity are visible in the selected outputs. Each is 1200×800; sizes and the exact prompt set are recorded in docs/IMAGE_ASSETS.json. The initial desk output with lettering was discarded. No external stock-photo licence is claimed.
